# Étape 5 · Expliquer un code que je n'ai pas écrit

1. Ouvrez un fichier modifié par la PR que vous avez fusionnée.
2. Tirez 10 lignes au hasard (par exemple les lignes données par un dé ou un générateur de nombres).
3. Expliquez-les **sans relire le code** : enregistrez-vous 2 minutes (audio ou vidéo, avec votre téléphone), ou écrivez l'explication ci-dessous.
4. Réécoutez-vous et cochez :

- [ ] J'ai expliqué les 10 lignes
- [ ] Je sais pourquoi chaque ligne est là, pas seulement ce qu'elle fait
- [ ] Je pourrais modifier ce code moi-même

**Fichier et lignes tirées :** …

**Mon explication (si écrite) :** …
